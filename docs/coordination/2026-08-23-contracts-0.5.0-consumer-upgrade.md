# Contracts 0.5.0 consumer-upgrade notice — the `AGWF035` diagnostic code

**Date:** 2026-08-23
**Author drafted for:** lvlup-sw/strategos maintainer to action manually
**Status:** Drafted — not yet filed

`LevelUp.Strategos.Contracts` moves **0.4.0 → 0.5.0**, adding one AGWF diagnostic
code: `UnreachableTermination` / `AGWF035`.

The addition is schema-additive (a new enum member and a new catalog entry), so it
is a minor bump — but the **upgrade must be sequenced consumer-first**. The emitted
`AgwfCode` enum round-trips by NAME through a converter that throws on a member it
does not know, so a consumer still pinned to 0.4.0 cannot deserialize any payload
carrying `AGWF035`. Strategos must not emit the code into a cross-product payload
until every consumer below is on 0.5.0.

The implementer agent does NOT have permission to file issues or post comments on
behalf of the maintainer; this file is the staging area for the actions the
maintainer takes after merge. That is why the in-repo record exists at all: the
sequencing obligation is real whether or not anyone remembers it.

## Issue body (same text for each repository)

**Title:** `Upgrade LevelUp.Strategos.Contracts to 0.5.0 before Strategos emits AGWF035`
**Labels:** `contracts`, `dependencies`

```markdown
## Context

`LevelUp.Strategos.Contracts` 0.5.0 adds one AGWF diagnostic code:

- `UnreachableTermination` — wire value `AGWF035`, severity `error`, since `2.11.0`.

It reports a workflow whose main flow chains into a step reached only through its
own construct — a fork path, a branch case, a failure or approval handler, or a
low-confidence handler chain — so the saga runs past its declared termination
instead of completing. The whole failure class is decidable at generation time;
until now the only thing that caught it was a container-backed saga run.

## Why this sequences before the Strategos upgrade

The emitted `AgwfCode` converter round-trips by NAME and **throws on an unknown
member**. A consumer pinned to 0.4.0 therefore cannot deserialize a payload
carrying `AGWF035`. Upgrade this repository first; Strategos emits the code only
once every consumer is on 0.5.0.

## Required change

- Bump the `LevelUp.Strategos.Contracts` package reference to `0.5.0`.
- (exarchos only) Add the `UnreachableTermination` member to the TypeScript
  `AgwfCode` enum, mapped to `"AGWF035"`, and regenerate any pinned snapshot.
- No other contract changed: the bump is additive, and the structural schema diff
  reports it as non-breaking.

## Reference

- `src/Strategos.Contracts/Diagnostics/AgwfCatalog.tsp` — the canonical source.
- `src/Strategos.Contracts/Generated/agwf-catalog.json` — the emitted catalog.
- `docs/diagnostics/agwf.md` — the human reference table.
```
